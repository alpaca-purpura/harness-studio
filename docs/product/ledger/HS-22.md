  aunque venga de mirrors; registry-de-adquisición = **faceta N:M**. Relación arnés–empresa–registry = **N:M:M** (lentes, no dueños).
- **Canónico** (única copia editable) + N **instalaciones** (espejos read-only). **Ley anti-drift** (reformulada DESCRIPTIVA de
  ArnesIA): ArnesIA nunca introduce una copia editable divergente nueva; observa + re-materializa (reparar) + backportea;
  `home`/marketplace = SSoT (pull-antes-de-push). **`deriva`** (ex-«drift») = hash de contenido vs `home/plugins/<id>/<versión>/`.
- **IA = 3 superficies** (Lista · Wizard agregar · Drawer detalle). Mockup v2 `mockups/arnesia-portafolio.html` aprobado por el operador.

estaba indefinido y el mockup lo FABRICABA (viola la honestidad del repo). (3) `(registry,id)` se contradecía sola (fractura
