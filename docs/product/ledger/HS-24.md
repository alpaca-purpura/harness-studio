# HS-24 · Convención de versionado de instaladores locales — FIRMADA

> vig: activo · ficha (LEDGER) · HS-24 · gate 🧑‍⚖️ FIRMADO 2026-07-15

### HS-24 · IL-D9 firmada: `make installer` + `instaladores/vX.Y.Z/` — `decidida` · `vig:vigente`

*Contexto:* nace de un bug real (botón "Elegir carpeta" del shell Tauri bloqueado por ACL —
el permiso `dialog:allow-open` vive compilado dentro del bundle, no es hot-patchable; el
self-update del daemon solo reconstruye el binario Go, nunca el shell). Al resolverlo se
detectó `Makefile`/`instaladores/` sin trackear y sin cablear al router (`CLAUDE.md`), y una
convención (`docs/architecture/conventions/versionado.md`, IL-D9 en
`docs/product/stories/2026-07-15-instalador-publico-licencias-org/decisiones.md`) escrita el
mismo día pero nunca firmada.

*Firma (operador, 2026-07-15):* "fírmala de una vez" — decisión IL-D9 ratificada:

1. `Cargo.toml` = SoT de versión (semver plano `X.Y.Z`, sin prefijo `v` — formato exacto que
   exige `Release.version` de Keygen) ✅
2. `make bump-patch` sincroniza los 3 manifiestos (`Cargo.toml`/`tauri.conf.json`/
   `package.json`) ✅
3. `make installer` = bump + `scripts/bundle.sh` completo + copia versionada a
   `instaladores/vX.Y.Z/` + `checksums.txt`; nunca pisa una carpeta `vX.Y.Z/` existente ✅
4. Enforcer real verificado en vivo: `TestVersionManifestsInSync`
   (`docs/architecture/fitness/arch_test.go`) — PASS ✅

*Cierre:* `versionado.md` `status: proposed` → `enforced`, `ledger: ninguno` → `HS-24`.
`decisiones.md` IL-D9 header → FIRMADA. `CLAUDE.md` router gana fila nueva ("Armar/actualizar
instalador de escritorio" → `versionado.md`) — el gap real que causó el olvido no era solo
falta de firma, era falta de cableado al router que se inyecta solo cada sesión; ver
[[hs-instaladores-make-installer]] (memoria de sesión, corrección de proceso).

*Desviación aceptada sin objeción:* `sot-unica` (nadie puede distinguir a nivel de git diff
una edición manual de versión de una hecha por `make bump-patch`) sigue sin enforcer — queda
`warn`, no bloquea la firma.

*Fuera de alcance:* el resto del paquete `instalador-publico-licencias-org` (instalador público
`curl | sh`, licencias Keygen por organización — IL-D0..D8) sigue en `idea`, sin firmar,
bloqueado en IL-D6/IL-D7. Esta ficha firma SOLO IL-D9 (tooling de build local), decisión
explícitamente decoupleada del resto ("no bloquea `refining`").
