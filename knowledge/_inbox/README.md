# _inbox — buzón de la cadencia semanal

Aquí caen los reportes de cada corrida del update semanal (`<AÑO>-W<ww>.md`), generados por el
routine programado o por el botón «Actualizar estándar» del mapa. Runbook:
[`../WEEKLY-UPDATE.md`](../WEEKLY-UPDATE.md).

**Qué contiene cada reporte:** evidencia L1 auto-aplicada (tier híbrido) + **propuestas pendientes
de revisión** (L2, checks, elementos nuevos — nada de esto se aplica sin OK del operador).

**Flujo del operador:** leer el reporte más reciente → aprobar/rechazar propuestas → el asistente
aplica las aprobadas → mover el reporte a `procesados/` o marcar `revisado: <fecha>`.

llega en la primera corrida semanal.
