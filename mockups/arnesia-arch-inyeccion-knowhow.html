Inyección de know-how a Claude Code

ArnesIA · cómo la fábrica posee su doctrina y la implementa
HS-07 · insumo · 2026-07-05

El usuario instala Claude Code, instala ArnesIA, y usa ArnesIA. Nunca entra a Claude Code a configurar nada. Todo el know-how de cómo se hace el mejor arnés viaja con el binario y se aplica por detrás. El diseño entero cuelga de separar tres cuerpos y hacerlos converger en un solo spawn.

Restricción cero-config. Instalar CC (con suscripción activa) → instalar ArnesIA → usar. Los updates los aplica ArnesIA. El usuario no toca ~/.claude ni corre /plugin install jamás.

El mecanismo estrella

Un spawn: los tres cuerpos convergen

--plugin-dir carga la maquinaria para esa sesión — sin install, sin tocar el árbol del usuario, y sin --bare, así la suscripción del claude local queda intacta.

internal/adapters/agent/claudecode/conductor.go · Spawn()
claude -p --input-format stream-json --output-format stream-json --verbose  # base (HS-06)
  --resume ID  --model M  --max-turns N                        # sesión viva (HS-06)
  --cwd ~/arneses/luana-platform                          # ③ editar el arnés-producto
  --plugin-dir ~/.arnesia/kit                             # ② meta-arnés (skills+subagents+hooks)
  --append-system-prompt-file ~/.arnesia/doctrine.md      # ① doctrina (overlay)
  --add-dir ~/.arnesia/knowhow                            # ① los 122 checks (read-only)
  --mcp-config ~/.arnesia/mcp.json                        # sensor + langfuse-espejo
  --permission-mode …                                     # spike control_request (HS-07)
③ producto cwd ② maquinaria --plugin-dir ① doctrina --append-system-prompt-file telemetría --mcp-config base HS-06
⚠️
--bare y suscripción-propia son excluyentes. Bare salta OAuth y exige ANTHROPIC_API_KEY. Elegimos suscripción-propia (legítimo: app local sobre el CC del propio usuario). La zona prohibida por terms es hostear login de terceros — no es nuestro caso. Nada de --bare.

Una fuente, dos targets

El know-how tiene dos representaciones

Lo que vuelve real el principio 10 («nada sin eval»): la misma doctrina se compila en un ruleset ejecutable y en una guía generativa.

Como DATA

ruleset.json → arnesia conformance

Runner Go, sin LLM. Barato, exacto, determinista. Es el gate estático: cargar → chequear → reporte de brechas → corregir.

Como PRIMITIVAS CC

kit/ → el conductor genera conforme

Skills tipo authoring-a-skill-caja + subagents de forja. LLM, para crear y mejorar el .claude/ del arnés.

ambas derivan del mismo knowledge/elements/*.md — el build las mantiene sincronizadas · drift = check rojo

✓ Auth · resuelta

Local-first, suscripción-propia, sin --bare.

✓ Formato ② · resuelto

--plugin-dir session-scoped, no install persistente.

◔ Abiertas · HS-07

Sandbox/auto mode (cwd no es frontera) · aislar build vs eval · DevHub carga ③.
