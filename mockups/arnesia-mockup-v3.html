Estándar de ArnesIA

El estándar as code que ArnesIA enforca sobre todo arnés. Cada elemento define cómo debe estructurarse según Anthropic y los expertos (L1) y nuestra adaptación a la fábrica de cajas (L2), y emite checks evaluables que el mapa pinta como puntos de mejora. Árbol vivo: se actualiza cada semana — mañana aparecen comandos, formas de trabajar y hasta elementos nuevos.
